# Support

- **Documentation**: [`docs/`](docs/) (French, English, Spanish).
- **Bugs and feature requests**: [GitHub issues](https://github.com/xolo-gateway/xolo/issues).
  Check existing issues first.
- **Questions**: open an issue as well; there is no separate forum yet.
- **Security issues**: never in a public issue, see [SECURITY.md](SECURITY.md).

Issues and pull requests may be written in English or French.

Support is provided on a best-effort basis by the maintainers. There is no SLA
on the open source project itself.
