# Administrer une organisation

Cette section s'adresse aux administrateurs d'une organisation. Chaque page décrit un écran du menu d'administration et les opérations qu'on y fait.

| Page | Description |
| --- | --- |
| **[Membres](./membres.md)** | Gestion des rôles utilisateurs et des invitations |
| **[Rôles](./roles.md)** | Création et configuration des rôles et permissions |
| **[Équipes](./equipes.md)** | Regroupement des membres, accès aux modèles et budgets par équipe |
| **[Invitations](./invitations.md)** | Création de liens d'invitation pour intégrer des utilisateurs |
| **[Budget](./budget.md)** | Gestion des budgets (journalier, mensuel, annuel) pour contrôler les dépenses |
| **[Fournisseurs](./fournisseurs.md)** | Gestion des fournisseurs LLM et de leurs modèles |
| **[Modèles virtuels](./modeles-virtuels.md)** | Création de modèles personnalisés avec plugins (anonymisation, prompts système) |
| **[Middlewares](./middlewares.md)** | Ajout de traitements dynamiques (contrôle horaire, filtrage, garde-fous) appliqués aux modèles |
| **[Applications](./applications.md)** | Configuration d'applications pour l'utilisation de la passerelle (exemple : OpenWebUI) |
| **[Paramètres](./parametres.md)** | Gestion de la devise de l'organisation et du partage équitable du budget |

## Pour aller plus loin

Les [guides](../guides/index.md) construisent quatre modèles virtuels complets, et la section [Découvrir](../decouvrir/index.md) explique le modèle de permissions et le calcul des budgets.
