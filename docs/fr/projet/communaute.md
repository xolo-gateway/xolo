# Communauté

Xolo est un logiciel libre, développé en public. Voici où retrouver ses
utilisateurs et ses mainteneurs.

## Discuter

Le canal Matrix [#xolo:matrix.org](https://matrix.to/#/#xolo:matrix.org)
est le lieu de discussion du projet : questions d'installation ou d'usage,
retours d'expérience, annonces des nouvelles versions, échanges avec les
mainteneurs. Il est public et ouvert à tous ; un compte sur n'importe quel
serveur Matrix suffit pour le rejoindre.

Les questions peuvent être posées en français ou en anglais.

## Signaler un bug, proposer une fonctionnalité

Le suivi se fait sur le [dépôt GitHub](https://github.com/xolo-gateway/xolo) :

- une [issue](https://github.com/xolo-gateway/xolo/issues) pour un bug ou une
  demande de fonctionnalité ;
- une pull request pour une correction ou une amélioration de la
  documentation, en suivant le guide [Contribuer à Xolo](contribuer.md).

Les vulnérabilités ne se signalent pas en public : voir la
[politique de sécurité](securite.md).

## Se faire accompagner

Des entreprises proposent de l'accompagnement autour de Xolo (installation,
hébergement, formation, développement de plugins). Elles sont listées sur la
page [Trouver un expert](https://xolo-gateway.org/latest/experts/).
