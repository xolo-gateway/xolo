# Xolo

_Guiding your enterprise safely to the realm of AI._

> ⚠️ **Disclaimer**
>
> Xolo is currently under active development and should be considered a work in progress. The API is in a preliminary stage and may not be stable. Please be aware that changes, including modifications, updates, or deprecations, can occur at any time without prior notice.

## Features

- **Authenticate** users via OIDC
- **Proxy** OpenAI-compatible LLM requests
- **Control** usage with fine-grained quotas for users
- **Monitor** everything, keep full visibility over your AI usage
- **Deploy** anywhere, self-hosted, on-premise, fully under your control
